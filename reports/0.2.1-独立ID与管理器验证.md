# KSA Babel 0.2.1：独立 ID 与管理器验证

日期：2026-10-24。当前仍是九语种预览版，仅适配 Windows x64、KSA 2026.10.19.5638 的已检查文件与 StarMap 0.4.8。新增语言尚无独立母语审校，审核底稿的条目完整不代表全游戏覆盖。

本报告保留 0.2.1 的历史范围；其构建与包报告已归档到 `history/0.2.1/`。当前正式版为 0.2.2，见[正式发布报告](0.2.2-正式发布与验证.md)。根目录同名构建与包报告现在记录最新构建。

## 独立身份与迁移

- 模组 ID、安装目录、包名前缀改为 `KsaBabel`，插件为 `KsaBabel.dll`，便携入口为 `KsaBabel/KsaBabelLauncher.exe`。源码目录和代码命名空间继续保留 `KsaChinese`，它们不是安装 ID。
- 新设置为当前游戏档案的 `KsaBabel/settings.json`。仅当新文件不存在时，读取同一档案旧 `KsaChinese/settings.json` 中有效、受支持的 locale，并原子写入新文件；只导入语言，不复制其他字段，不修改旧文件，不搜索其他档案或自动移动存档。
- 已有新设置（包括损坏文件）不会被旧设置覆盖。旧文件缺失、损坏或语言未知时回退默认；迁移保存失败时仅在本次会话使用有效旧语言并记录原因。
- 在 `BeforeMain` 的初始化和补丁安装之前读取 StarMap 已准备好的完整启用清单。旧 `KsaChinese` 启用时 Babel 拒绝激活。Harmony 补丁所有者也改为 Babel 专用标识，避免误卸载旧项目的补丁。
- 索引模板声明对 `KsaChinese` 的 conflict。Borea 的安装规划拒绝已安装旧 ID 的实例，故管理器迁移需要移除旧模组条目并保留档案；单纯禁用旧模组只满足运行时守卫。

## 验证结果与边界

1. **无图形验证：1,213 项检查、715 个目标引用通过**，构建零警告、零错误。新增设置迁移、保留旧文件、已有新文件优先、错误与不可写回退、实际 BeforeMain 冲突入口、启动器版本/哈希保护检查。见 `5638-bootstrap-validation.json`。构建输入指纹记录本地工作树字节；Git 的换行归一化可能改变文本文件字节，重新构建应重新生成验证。
2. **打包守卫：** 插件、语言资源、Launcher 源码以及四个 Launcher 产物都必须匹配成功验证。替换 Launcher 的负测被拒绝，恢复已验证字节后通过。
3. **九语言真实游戏：** 在独立 `work/test-profile-babel-021` 中加载新程序集，九次切换、原生文本/字体选择与九张截图齐全，退出码 0、stderr 为空；暂停场景的三处固定数码像素区域跨语言一致。游戏文件十项指纹保持不变。见 `multilingual-game-validation.json`。这不是本轮完整人工视觉验收，也不证明所有窗口、分辨率或长时间稳定性。
4. **Borea 无图形管理流程：23 项检查通过。** 使用未修改的 Borea 0.5.1 源组件（提交 `284d5cf929c8ede99320f8afc451fa44f12aeadd`）、本地候选索引和实际 ZIP。两实例安装、游戏版本/平台约束、旧 ID 冲突规划、启用/禁用、真正执行版本更新及 DLL 哈希变化、卸载和实例隔离均通过。设置、旧设置与 saves 目录中的所有权测试文件字节保持不变；该文件是哨兵，不是可玩的游戏存档。见 `ecosystem-validation.json`。
5. **启动证据分开记录：** 此前完整图形流程中，Borea 已成功启动新 0.2.1 的 Babel B 实例并退出 0，证据见 `borea-launch-validation.json`。后续另一次启动因窗口最小化暂停渲染、达到超时；恢复后游戏完成存档加载，但原验证程序已超时，不能记为整套图形流程通过。用户停止电脑控制后，最终管理流程使用 `--management-only`，只记录启动计划，未创建游戏进程、未做 UI 自动化。该计划指向实例安装的 StarMap 并传入独立档案；它不能冒充一次新的真实启动。
6. **上游元数据：** 六项本地规范检查通过，原版 stamper 能识别标准包并排除便携包，兼容范围与 conflict 已进入候选快照。使用明确的本地合成旧版本 `KsaBabel 0.2.0` 夹具测试升级机制，两版均为 testing 通道、DLL 字节不同。它由当前源码以不同版本构建，不是公开旧 v0.2.0，也不证明历史代码版本迁移。论坛 URL 为忽略目录内的合成输入；真实论坛 URL 仍待发布，不代表最终公开条目已通过检查或收录。见 `ecosystem-metadata-validation.json`。
