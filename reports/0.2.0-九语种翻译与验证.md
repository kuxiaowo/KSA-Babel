# 0.2.0 九语种翻译与验证

日期：2026-10-24。目标游戏：精确版本 `2026.10.19.5638`，StarMap `0.4.8`。

本轮在原有显示层框架上完成 Steam 版 KSP 所列九种语言的 KSA 翻译预览：英文、简中、日语、俄语、德语、法语、意大利语、西班牙语及巴西葡萄牙语。七种新增语言各覆盖现有简中审阅底稿中的 **4,786 条记录**，另外增加 **11 个动态模板**。英文直接回退游戏原文。译文、数据和构建均在 `developing` 工作区完成，尚未提交推送、创建 PR 或公开发布。

这是对已有底稿的完整性统计，不是全游戏覆盖率。更早更新正文、原生工具库和异常文本、模型与贴图印字、部分动态状态与未盘点的调用仍可能显示英文。不同语言的单位、缩写、型号或技术术语可能合理地与英文相同，不能用“字符串变化率”衡量质量。

新增译文标为 `ai-reviewed`，记录来源并结合当前英文、已审中文、物理量和调用语境核对。通过格式检查和 AI 交叉审阅，**没有取得独立母语审校**。各语言的措辞、性数格、复合词、窄控件缩写和排版仍需要实际使用反馈，不能称作官方级或最终质量验收。

650 条部件名使用逐语言显式编写的 283 个完整名称模板展开，保留型号、部件规格和编号槽位；不是对任意界面文本逐词替换。物质与药柱记录使用完整名称、说明的显式译文。更新正文按原版本发生顺序翻译，没有把曾经的限制或历史修复误称为当前状态。

## KSP 参考和许可

本机 KSP 为 Steam 版 1.12.5，仅安装简中资源。其他八种语言的参考来自公开镜像 `Apofoo/KSP-Localization` 固定提交 `d0af1776af29f00f63522bf3d9b36ef9e1a83b9c`，与本机中文资源按版本和哈希核对：本体／Making History 和 Breaking Ground 两份中文文件均逐字节一致。其他语言未从官方 depot 独立验证，因此来源明确标为镜像。

本体／Making History 九语言共同 `autoLOC` 键有 11,929 个，Breaking Ground 为 724 个。它们仅在 Git 忽略的 `work/multilingual-20261024/ksp-reference/` 作术语对照，未复制整个词典或大段 KSP 说明文字到新运行包。按相同英文仍需判断物理量和 UI 语境，例如 `RATE` 在仪表按钮表示消旋，`NORM` 表示正常模式，而 `NORMAL` 为轨道法向。

日语核心有 1,523 条同区段／键的初始候选来自 LiX-Works/KsaUiLanguages 的 MIT 提交 `61779119c18c994b8bf59458d2979100c9855dc3`，来源保留在每条记录与 THIRD_PARTY 中；当前缺项另行独立翻译。没有整合此前无明确许可的长夜月、西语、世界语或法语项目词库。全部代码和译文的 MIT、字体 OFL、加载器及 Harmony 署名继续保留。

分工过程中曾试探单条公共翻译接口，并生成少量隔离草稿；该流程已停止，缓存仅留在忽略目录且没有用作产品译文。所有发行译文以逐条来源台账为准。

## 实现与验证方式

- 继续使用原 StarMap／Harmony 显示层方案，内部模组 ID、程序集名及每档案语言偏好路径保持为 `KsaChinese`，语言菜单显示九种语言。
- 将中文专用的相态名称、混合比提示、轨道近点角与分析器窗口前缀改为语言模板。液体、气体、固体等采用独立模板，避免其他语言混入中文或错误套用前缀。
- 所有非英语仪表使用有对应字形的共享字体；语言切换清除仪表缓存。欢迎文本支持假名换行，保留操作标签及快捷键对象。
- 资源条的名称和完整数值单位分两行；分级的 Isp／TWR 分列拟合，总 Δv 先给完整数值留出空间。仪表按钮仍走游戏原生绘制，部分长文案在窄控件内可能偏密，尚未逐控件完成所有语言视觉验收。
- 不改游戏原始资源、控件／存档／绑定 ID、物理参数、单位、枚举数据、型号或玩家名称，未知版本及文件哈希继续安全拒绝。
- `build_multilingual.py` 检查全量 ID、空值、重复条目、花括号参数、printf、markup 顺序及 ASCII `: ` 布局分隔符；不完整时拒绝生成运行包。打包还校验当前源码和资源哈希对应已通过检查的插件构建，避免误打包过期词典。

静态／无图形验证证据：`multilingual-validation.json`、`multilingual-runtime-contracts.json`、`5638-bootstrap-validation.json` 和 `font-validation.json`。目前完整底稿检查为七语言各 4,786 条、零结构格式错误；共享字体所需 2,503 码位均有 cmap 映射。该字体源为 Noto Sans SC，因此码位齐全不代表所有日语汉字采用日本地区字形，也不保证任意玩家命名的全部字符。

最终无图形构建零警告、零错误；通过 **1,194 项检查、715 个补丁目标引用**，包括九语言真实原生资源提供器、UTF-8、ImGui 控件 ID、英文回退、独立档案语言偏好往返、相态原对象字段不变、动态数值保留和资源／分级布局合同。这不等同于真实游戏窗口遍历或母语验收。

独立 AI 复核的结果另保存在 `multilingual-independent-review.json`：结构硬错误为零，22 组语义样本，300 项数值差异提示已按部件规格展开、文字与数字转换、合金命名等分类。其中日语第 1–4 象限、四分之一显存与每秒表述、俄语“3D”的文字写法，以及德语 Apollo-11 的连字符均另核对；`Titanium.64` 对应原资源名 `Titanium Alloy 6-4`，资源 ID 没有改变。抽查和分类不能证明全部译文语义正确。

## 游戏测试及交付状态

游戏测试使用新的工作区 `test-profile`，不读取个人存档。第一次测试发现隔离游戏副本 `Content/KsaChinese` 的旧双语包覆盖了新档案中的九语种包；旧测试副本已移至可恢复的工作区备份。测试工具增加实际程序集路径检查，并要求完整的九语言结果文件与完成标记，不能只靠退出码 0 判成功。

最终游戏测试档案为 `work/test-profile-multilingual-020-layout`。精确版本 5638 中依次切换 en-US、ja-JP、ru-RU、de-DE、fr-FR、it-IT、es-ES、pt-BR、zh-CN；九种原生分辨率标签和字体选择均核对，实际插件路径和哈希与最终无图形构建一致。原生仪表文字路径在每种语言下都有执行记录。实际生成 **9 张 1920×1080 PNG**，日志有完整结束标记、stderr 为空、进程退出码为 0，测试进程已结束。

截图检查中曾把缩略图误读为数码丢失，后改用原始 PNG 像素核实：固定暂停场景的剂量、远点和 Δv 三块数码区域，在九种语言间 **RGB 字节逐像素一致**，同时有足够的明亮文字像素，未出现此前推断的数码缺失。不能据此声称其他仪表、其他状态或动态读数也已全部验收。额外自定义仪表／下拉框拟合没有保留在最终插件中；最终保留游戏原生仪表绘制及已通过合同检查的资源、分级布局。

游戏原安装的 10 项兼容性文件哈希仍全部匹配；测试只用工作区独立档案，没有安装到个人游戏档案或改动个人存档。原始 KSP 词典、游戏 DLL 和反编译材料均不进入包。尚未完成全窗口、分辨率及长时间游戏遍历，新增语言也没有母语审校；不能据此宣称全部界面排版无误。

最终游戏结果、原图相对路径和数码区域哈希见 `multilingual-game-validation.json`。可用 `scripts/summarize_multilingual_game.py --profile work/test-profile-multilingual-020-layout --tag multilingual-020-layout --game-dir <本地游戏目录>` 重新核验；截图检查工具需要 Pillow。
