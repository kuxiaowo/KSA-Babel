# KSA Babel 项目迁移与公开验证

日期：2026-10-24。仓库：https://github.com/kuxiaowo/KSA-Babel 。许可证：MIT；字体与第三方组件分别遵守原许可证。项目中文名为“喵语塔”。

## 来源与目录

从原 KSA-CHINESE 当前工作快照复制 230 个可分发文件，包含源码、九语言资源、逐条翻译决策、工具、许可证、历史报告和已公开截图。原仓库的未提交工作没有重置、移动或提交；它们在新仓库独立发展。迁移前逐文件哈希与公开基线提交见 project-origin.json。

公开品牌改为 KSA Babel；为兼容档案与加载器，内部 KsaChinese ID、程序集、语言设置目录及安装包前缀保留。不得同时启用 Babel 与原 KSA Chinese。Babel 尚未单独获得 Borea 收录，旧生态记录明确标为原项目历史；未向论坛或外部索引提交内容。

旧版安装器与 0.1.x 报告保留为历史材料，不作为 Babel 当前兼容性或已发布证明。整套工作目录、开发依赖、游戏与 KSP 原资源、反编译文件、个人档案及缓存均不上传。

## 迁移与构建验证

- 默认游戏路径改为显式参数或 KSA_GAME_DIR；加载器支持显式参数或 KSA_LOADER_DIR，默认只查项目 .tools 目录。
- SmokeDriver 按真实项目根目录和 work/test-profile* 边界验证，拒绝目录联接及路径越界；脚本临时环境变量成对恢复。独立路径守卫、缺参数和恢复负测已执行。
- 新目录首次验证发现旧临时输出目录依赖，现改到自动创建的隔离 fixture，不需要迁移旧审计工作区。
- 新目录完整构建零警告、零错误，通过 **1194 项检查、715 个目标引用**。证据：5638-bootstrap-validation.json。
- 七种新增语言各 4,786 条记录和 11 个动态模板通过结构与新鲜度检查；2091 个语言包所需码位在随包字体中均存在。码位覆盖不代表日语地区字形或任意玩家名称完整。

## 新目录游戏验证

在新的隔离测试档案 `work/test-profile-babel-020` 中真实加载九语言，实际插件与当前构建 SHA-256 匹配。九张 1920×1080 截图全部生成，原生标签和字体选择、原生仪表执行记录齐全；stderr 为空、退出码为 0。固定暂停场景的剂量、远点和 Δv 三处数码区域与英文 RGB 像素逐字节一致。记录见 multilingual-game-validation.json；原图和个人路径不上传。

这不代表全游戏覆盖、所有窗口/分辨率/长时间游戏通过；新增语言是 AI 翻译与复核预览，尚无独立母语审校。其他窗口和较长标签仍需更多实际反馈。

## 公开检查与许可

保留 KSA Chinese、KsaUiLanguages 的 MIT 署名；新增 KSA Babel 贡献者版权。StarMap/Harmony MIT、Noto OFL 与原字体来源记录完整保留。KSP 原词典仅作本地术语参考，不进入源码或安装包。

publication-audit.json 记录可分发文件、常见凭据模式、私密路径与字体检查。历史文本中的本机路径已泛化。29 张历史截图经 GitHub 原项目公开提交逐个校验 Git blob，全部字节一致，见 inherited-screenshot-provenance.json；它们是原有公开验证图，不代表一次完整 OCR/隐私审计。游戏画面权利归原权利人，不按本项目 MIT 重新授权。
