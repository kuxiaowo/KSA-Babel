# KSA Babel 0.2.2：正式发布与验证

日期：2026-10-25。0.2.2 为正式软件发布，目标通道为 `stable`。仍仅支持已检查的 Windows x64 KSA 2026.10.19.5638、StarMap 0.4.8 和 .NET 10 x64 Runtime。

公共目录会固定一个已收录版本的 `release_status`；原 0.2.1 的 `testing` 记录不能通过普通元数据修订改成 stable。因此保留原 0.2.1 预览版与其安装包，使用新版本 0.2.2 发布正式包，不覆盖旧标签或下载内容。

## 本版变化

- 插件、启动器及 `mod.toml` 版本一致为 0.2.2；更新当前安装说明、九语言 README 和目录描述。
- 正式发布使用默认 stable 通道，不再要求开启测试通道。
- 沿用维护者选定的 v3 九语言封面、独立 ID `KsaBabel`、档案设置迁移和旧 `KsaChinese` 冲突保护。
- 本版没有修改显示补丁逻辑、语言包内容、字体、兼容哈希或存档行为。

正式发布状态不代表译文已经全部通过人工审校。只有简体中文由维护者本人确认；其他七种语言仍为 GPT 结合 KSA 语境、参考 KSP 航天术语翻译与复核，尚无独立母语审校。英文仍使用游戏原文及新增 Language 菜单。未翻译内容回退原文，覆盖限制继续保留。

## 验证与边界

1. 插件、启动器和验证程序重新构建，零警告、零错误。插件与启动器的程序集版本均为 `0.2.2.0`。
2. **1,213 项无图形检查、715 个目标引用通过**。当前构建输入与输出指纹见 [5638-bootstrap-validation.json](5638-bootstrap-validation.json)。重新构建需要生成自己的输入字节指纹，Git 换行归一化可能改变文本文件字节。
3. 两个 ZIP 的完整性、文件清单和每个载荷哈希均通过；包内 `mod.toml` 为 0.2.2，安装 ID 与程序集入口均为 `KsaBabel`。标准包不含加载器，便携包保留 StarMap/Harmony 许可；没有个人存档或游戏本体文件。
4. 使用上游原版 stamper 和本地 0.2.2 正式发布事实夹具，得到 `version = 0.2.2`、`release_status = stable` 和正确安装根目录。夹具仅验证本地打包规则，最终公开日期和通道以 GitHub Release 与公共快照为准。
5. 此次不启动游戏或操作桌面。此前九语言实机切换和 Borea 管理组件验证属于 0.2.1 的历史证据，不能表述为本轮又完成了一次图形验证。相关范围见 [0.2.1 报告](0.2.1-独立ID与管理器验证.md)；旧构建报告已归档至 [history/0.2.1](history/0.2.1/5638-bootstrap-validation.json)。
