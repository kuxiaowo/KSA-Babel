# KSA Babel 0.2.4 · 5801 适配与验证

适配 Windows x64 KSA 2026.11.10.5801 与 StarMap 0.5.4。使用本机更新后的游戏副本与独立档案。兼容清单记录 KSA.dll 和另外 11 个文件的 SHA-256，加载器 ZIP 与上游资产 SHA-256 一致。 [5801 更新日志](https://github.com/KSAModding/ksa-versions/blob/264b79011c539f0ea761bd8fead579bc1e74414a/Content/Versions/v2026.11.X.5801.json) · [StarMap 0.5.4](https://github.com/StarMapLoader/StarMap/releases/tag/0.5.4)

## 适配

- 补译生命保障、乘员状态和死因、居住区与 EVA 物资、辐射及生命保障开关、储罐提示、撤销重做、部件变体与 HDR。核对部件的 Modify、Parent、Key、Ref 和新 ID。实际资源、存档键、型号、数值和玩家命名保持原样。
- 更新 242 行 5801 日志正文，保留游戏作者、修订号和日期。源文件中单字符残句保留为 y。简中与 KsaChinese 共用 5801 审核底稿，英文继续使用游戏源文本。
- 七个扩展语种各有 5,716 条底稿决策及 11 个动态模板。5801 新译文以本地 Qwen 3.5 4B 为主要初稿，少量用 M2M-100 418M 补充，核心术语和异常条目另行复核。语言决定记录包含来源和检查状态。数据和词典通过占位符、格式与字形检查，译文尚无独立母语审校。 [多语种验证](multilingual-validation.json)

## 验证

- 构建和无图形检查通过 467 项，涉及 790 个补丁目标引用。测试含九语言原生文本、ImGui ID、动态格式、档案语言选择、字体、启动器和未知版本保护。字体子集覆盖 2,624 个所需码位。 [构建验证](5801-bootstrap-validation.json) · [字体验证](font-validation.json)
- 1920×1080 隔离实机逐一切换九种语言，读取并核对居住区、HDR 场景基准白和分辨率标签。每种语言触发仪表绘字并生成显示设置与居住区截图。 [运行验证](5801-runtime-validation.json)
- 本地生成并校验标准和便携 ZIP。包内容使用白名单，包含所需的许可和署名。 [标准包](mod-package-validation.json) · [便携包](portable-package-validation.json)

实机截图抽查仍可见窄 HUD 长文字裁切。Babel 此轮实机覆盖语言切换与上述界面，编辑器、EVA 转移和规则重载由同版本的独立 KsaChinese 测试。尚缺母语验收、全部界面状态和分辨率、物理 HDR 输出、长时间运行及 Borea 桌面测试。游戏版本查询收到 HTTP 502，测试场景完成且进程正常退出。

0.2.4 为开发版。公开的 v0.2.3 与 Borea 条目对应 5707。
