# KSA Babel · 喵语塔

[English](../../README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja-JP.md) · [Русский](README.ru-RU.md) · [Deutsch](README.de-DE.md) · [Français](README.fr-FR.md) · [Italiano](README.it-IT.md) · [Español](README.es-ES.md) · [Português (Brasil)](README.pt-BR.md)

Платформа многоязычной локализации для **Kitten Space Agency**, загружаемая через StarMap. KSA Babel предоставляет языковые пакеты, меню выбора языка в игре, адаптеры отображения и общий шрифтовой набор. Исполняемый файл и ресурсы игры не заменяются.

KSA Babel — самостоятельный многоязычный проект, выделенный из [KSA-CHINESE](https://github.com/kuxiaowo/KSA-CHINESE). Текущая версия — **предварительная 0.2.0**. Она поддерживает только **KSA 2026.10.19.5638** для Windows x64 с проверенными хешами файлов. Используемый загрузчик — **StarMap 0.4.8**.

## Языки и охват

English · 简体中文 · 日本語 · Русский · Deutsch · Français · Italiano · Español · Português (Brasil)

Каждый из семи дополнительных языков содержит **4 786 записей** в пределах уже проверенного китайского перевода и **11 динамических шаблонов**. Для английского используется исходный текст игры. Полнота набора записей **не означает полного перевода игры**. Новые переводы прошли контекстную проверку с помощью ИИ, **но не независимую приёмку носителями языка**. Старые журналы изменений, сообщения нативных библиотек и об ошибках, надписи на текстурах и некоторые состояния интерфейса остаются за пределами проверенного объёма. Узкие элементы управления и другие разрешения экрана требуют дополнительной визуальной проверки.

В текущий объём входят интерфейс, подсказки, детали, вещества и их фазы, приборы и часть текстов обновлений. Обозначения моделей, единицы измерения, подстановочные параметры, идентификаторы ресурсов, элементов управления и сохранений, значения перечислений и пользовательские имена сохраняются. При неизвестной версии игры загрузка безопасно отклоняется, а при отсутствии перевода используется исходный текст. Подмножество Noto Sans SC включает учтённые символы, но не гарантирует поддержку любых пользовательских имён или всех региональных начертаний японских иероглифов.

## Установка

Скачайте пакет из [KSA Babel Releases](https://github.com/kuxiaowo/KSA-Babel/releases). Пакеты версии 0.2.0 являются предварительными.

- **Если StarMap/Borea уже установлен:** используйте `KsaChinese-0.2.0.zip`. Поместите папку `KsaChinese` из архива в каталог `mods` выбранного профиля и включите этот мод. См. [обычную установку](../../README-生态安装.md).
- **Пакет с загрузчиком:** распакуйте `KsaChinese-0.2.0-5638-Portable.zip` в папку, содержащую `KSA.exe`, и запустите `KsaChinese/KsaChineseLauncher.exe`. См. [установку портативного пакета](../../README-便携Mod.md). Требуется .NET 10 x64 Runtime.

Для совместимости внутренний идентификатор мода, имя сборки, каталог настроек и префикс архивов остаются **`KsaChinese`**. **Включайте только одну копию:** не устанавливайте KSA Babel одновременно с KSA Chinese и не оставляйте одновременно `Content/KsaChinese` и `mods/KsaChinese` в профиле. Перед переходом создайте резервную копию существующих профилей. Личные сохранения не входят в пакет и автоматически не перемещаются.

Для нового проекта ещё не подавалась отдельная заявка на включение в публичный каталог Borea. Запись KsaChinese в старом каталоге и выпуск v0.1.6 относятся к исходному проекту и не являются источником загрузки Babel. Устанавливайте вручную из Release этого репозитория. Проект не отправлял сообщений на форум или сопровождающим индекса.

## Сборка и проверка

Используйте .NET 10 SDK, законно установленную копию игры строго поддерживаемой версии и [StarMap 0.4.8](https://github.com/StarMapLoader/StarMap/releases/tag/0.4.8). Поместите файлы загрузчика в `.tools/StarMap-0.4.8` или укажите путь параметром `-LoaderDir`. Для скриптов нужен Python 3; предпочтительно использовать conda.

```powershell
python scripts/build_multilingual.py --check
.\scripts\build.ps1 -GameDir 'D:\Games\Kitten Space Agency' -Validate
python scripts/package_mod.py
python scripts/package_portable.py
```

Локальный путь к игре можно задать переменной `KSA_GAME_DIR` вместо параметра `-GameDir`. Бинарные файлы игры, `.tools`, локальные профили и результаты сборки исключены из Git. Свежий клон не содержит игру, загрузчик, декомпилятор, входные данные аудита или справочные словари KSP. Для необязательных скриптов исторического аудита нужны отдельно подготовленные локальные входные данные.

Решения по переводу записаны в `translations/multilingual/<locale>/*.jsonl`. Скрипт `build_multilingual.py` сверяет идентификаторы, происхождение, статус проверки, подстановочные параметры и разметку с проверенной базой; неполные или устаревшие пакеты отклоняются. Создание пакета также требует успешной локальной проверки соответствующей сборки и отсутствия последующих изменений в исходниках и ресурсах. CI проверяет данные и шрифты без привязки к установленной игре; компиляцию с лицензируемой игрой и приёмку игрового процесса он выполнить не может.

Сгенерированный шрифт уже включён. Для его повторной сборки нужны fontTools и файл `.tools/NotoSansSC-variable.ttf`, SHA-256 которого совпадает с указанным в [FONT-SOURCE](../../assets/KsaChinese/FONT-SOURCE.txt). Изменения исходного шрифта требуют проверки. Сведения для идентификации загружаемого StarMap и лицензии сторонних компонентов приведены в [THIRD_PARTY](../../THIRD_PARTY.md).

Они сохранены для прослеживаемости происхождения, а не как свидетельство того, что Babel ранее публиковался или включался в каталог. Материалы проверки интерфейса ограничены записанной тестовой сценой, переключением языков, снимками настроек и HUD, а также фиксированными областями изображений с числовыми показаниями. Это не исчерпывающая визуальная приёмка.

В предложениях по переводу указывайте язык, английский оригинал, игровой контекст и рекомендуемую формулировку. Особенно полезна проверка носителями языка. Разработка и коммиты выполняются по схеме **`developing → pull request → main`**.
