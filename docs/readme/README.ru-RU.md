# KSA Babel · 喵语塔

[English](../../README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja-JP.md) · [Русский](README.ru-RU.md) · [Deutsch](README.de-DE.md) · [Français](README.fr-FR.md) · [Italiano](README.it-IT.md) · [Español](README.es-ES.md) · [Português (Brasil)](README.pt-BR.md)

Платформа многоязычной локализации для **Kitten Space Agency**, загружаемая через StarMap. KSA Babel предоставляет языковые пакеты, меню выбора языка в игре, адаптеры отображения и общий шрифтовой набор. Исполняемый файл и ресурсы игры не заменяются.

KSA Babel — самостоятельный многоязычный проект, выделенный из [KSA-CHINESE](https://github.com/kuxiaowo/KSA-CHINESE). Текущая версия — **предварительная 0.2.1**. Она поддерживает только **KSA 2026.10.19.5638** для Windows x64 с проверенными хешами файлов. Используемый загрузчик — **StarMap 0.4.8**.

**Проверка переводов и английский режим:** автор лично подтвердил только упрощённый китайский перевод. Японский, русский, немецкий, французский, итальянский, испанский и бразильский португальский переведены и проверены GPT с учётом контекста KSA и терминологии KSP; независимой проверки носителями языка пока нет. Часть начальных японских переводов взята из KsaUiLanguages под MIT с сохранением авторства. Английский режим показывает исходный английский текст KSA и добавленное модом меню `Language`. 11 динамических шаблонов служат для многоязычного вывода и возврата к оригиналу, а не означают 11 переписанных английских текстов.

**Китайская версия:** [KSA Chinese / KSA-CHINESE](https://github.com/kuxiaowo/KSA-CHINESE), ID `KsaChinese`, переключает английский и упрощённый китайский. Текущий выпуск — [v0.1.6](https://github.com/kuxiaowo/KSA-CHINESE/releases/tag/v0.1.6), стандартный архив `KsaChinese-0.1.6.zip`; проверены Windows x64 KSA 2026.10.19.5638 и StarMap 0.4.8. Есть отдельная [запись Borea](https://github.com/KSAModding/content-index/blob/main/listings/KsaChinese.toml). Babel — самостоятельная предварительная версия с девятью языками и ID `KsaBabel`. Не включайте оба мода в одном профиле.

## Языки и охват

Каждый из семи дополнительных языков содержит **4 786 записей** в пределах уже проверенного китайского перевода и **11 динамических шаблонов**. Для английского используется исходный текст игры. Полнота набора записей **не означает полного перевода игры**. Новые переводы прошли контекстную проверку с помощью ИИ, **но не независимую приёмку носителями языка**. Старые журналы изменений, сообщения нативных библиотек и об ошибках, надписи на текстурах и некоторые состояния интерфейса остаются за пределами проверенного объёма. Узкие элементы управления и другие разрешения экрана требуют дополнительной визуальной проверки.

В текущий объём входят интерфейс, подсказки, детали, вещества и их фазы, приборы и часть текстов обновлений. Обозначения моделей, единицы измерения, подстановочные параметры, идентификаторы ресурсов, элементов управления и сохранений, значения перечислений и пользовательские имена сохраняются. При неизвестной версии игры загрузка безопасно отклоняется, а при отсутствии перевода используется исходный текст. Подмножество Noto Sans SC включает учтённые символы, но не гарантирует поддержку любых пользовательских имён или всех региональных начертаний японских иероглифов.

## Установка

Скачайте пакет из [KSA Babel Releases](https://github.com/kuxiaowo/KSA-Babel/releases). Пакеты версии 0.2.1 являются предварительными.

- **Если StarMap/Borea уже установлен:** используйте `KsaBabel-0.2.1.zip`. Поместите папку `KsaBabel` из архива в каталог `mods` выбранного профиля и включите этот мод. См. [обычную установку](../../README-生态安装.md).
- **Пакет с загрузчиком:** распакуйте `KsaBabel-0.2.1-5638-Portable.zip` в папку, содержащую `KSA.exe`, и запустите `KsaBabel/KsaBabelLauncher.exe`. См. [установку портативного пакета](../../README-便携Mod.md). Требуется .NET 10 x64 Runtime.

Начиная с 0.2.1 идентификатор мода, каталоги установки и префикс архивов — **`KsaBabel`**; сборка плагина — `KsaBabel.dll`, а портативный лаунчер — `KsaBabel/KsaBabelLauncher.exe`. Язык сохраняется в `KsaBabel/settings.json` текущего профиля. При первом запуске Babel импортирует допустимое значение `locale` из старого `KsaChinese/settings.json` того же профиля, только если новый файл настроек ещё не существует. Существующий новый файл не перезаписывается, старый файл не изменяется.

**Сначала отключите старый мод:** Babel отказывается активироваться, пока включён `KsaChinese`. Оставьте только одну включённую копию Babel; не сохраняйте одновременно `Content/KsaBabel` и `mods/KsaBabel` в профиле. Перед переходом создайте резервную копию существующих профилей. Личные сохранения не входят в пакет и автоматически не перемещаются; импорт настроек не ищет файлы в других профилях.

[Объявление на Ahwoo](https://forums.ahwoo.com/forums/kitten-space-agency/mod-releases/ksa-babel-0-2-1-nine-language-localization-preview-for-ksa-5638.1454/) опубликовано, а [PR #227 для каталога Borea](https://github.com/KSAModding/content-index/pull/227) принят. Состояние обработки релиза и проверки публичного снимка см. в [записи о публикации](../../reports/community-publication-20261024.md). Существующая запись KsaChinese и выпуск v0.1.6 относятся к отдельному проекту для китайского языка. KSA Babel 0.2.1 уже есть в публичном каталоге как предварительная версия `testing`; используйте канал, допускающий тестовые версии.

При переходе через Borea сохраните резервную копию профиля и удалите старый мод KsaChinese из экземпляра перед установкой Babel. Конфликт каталога блокирует установку даже при отключённом старом моде. Сохраните данные профиля.

## Сборка и проверка

Используйте .NET 10 SDK, законно установленную копию игры строго поддерживаемой версии и [StarMap 0.4.8](https://github.com/StarMapLoader/StarMap/releases/tag/0.4.8). Поместите файлы загрузчика в `.tools/StarMap-0.4.8` или укажите путь параметром `-LoaderDir`. Для скриптов нужен Python 3; предпочтительно использовать conda.

```powershell
python scripts/build_multilingual.py --check
.\scripts\build.ps1 -GameDir 'D:\Games\Kitten Space Agency' -Validate
python scripts/package_mod.py
python scripts/package_portable.py
```

Локальный путь к игре можно задать переменной `KSA_GAME_DIR` вместо параметра `-GameDir`. Бинарные файлы игры, `.tools`, локальные профили и результаты сборки исключены из Git. Свежий клон не содержит игру, загрузчик, декомпилятор, входные данные аудита или справочные словари KSP. Для необязательных скриптов исторического аудита нужны отдельно подготовленные локальные входные данные.

Решения по переводу записаны в `translations/multilingual/<locale>/*.jsonl`. Скрипт `build_multilingual.py` сверяет идентификаторы, происхождение, статус проверки, подстановочные параметры и разметку с проверенной базой; неполные или устаревшие пакеты отклоняются. Создание пакета также требует успешной локальной проверки соответствующей сборки и отсутствия последующих изменений в исходниках и ресурсах. CI проверяет данные и шрифты без привязки к установленной игре; компиляцию с лицензируемой игрой и приёмку игрового процесса он выполнить не может.

Сгенерированный шрифт уже включён. Для его повторной сборки нужны fontTools и файл `.tools/NotoSansSC-variable.ttf`, SHA-256 которого совпадает с указанным в [FONT-SOURCE](../../assets/KsaBabel/FONT-SOURCE.txt). Изменения исходного шрифта требуют проверки. Сведения для идентификации загружаемого StarMap и лицензии сторонних компонентов приведены в [THIRD_PARTY](../../THIRD_PARTY.md).
